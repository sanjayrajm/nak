# MSR TECH SEO SEARCHER

A static, GitHub Pages-ready SEO analyzer and keyword planning website.

## Included
- On-page SEO heuristic analyzer
- Title and meta description checks
- H1/H2/H3 checks
- Content and keyword analysis
- Link and image-alt checks
- Keyword idea generator
- Responsive UI
- Canonical, robots.txt and sitemap.xml
- WebApplication JSON-LD structured data
- FAQ content
- Custom 404 page

## GitHub Pages
This repository is currently named `nak`. For a personal site at `https://sanjayrajm.github.io/`, rename the repository to `sanjayrajm.github.io` in GitHub repository settings, then enable GitHub Pages from the `main` branch/root.

The canonical URL and sitemap are already configured for the personal-site URL, so update them if you choose a project-site URL instead.
