FAQ

Does the user need an API key?

No. The intended production architecture keeps the Google credential on the backend. The user enters the website URL and receives the audit.

Can Google PageSpeed provide backlinks?

No. PageSpeed is for performance and Lighthouse diagnostics. Backlink analysis needs Search Console for your own property or a dedicated backlink-data provider.

Can SEO tools guarantee rankings?

No. They identify opportunities and measure signals, but search rankings depend on relevance, helpfulness, competition, links, crawling, indexing and many other factors.
